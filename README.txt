QÚNDYLYQ — дайын статикалық веб-платформа

Файлдар:
- index.html — негізгі бет
- style.css — дизайн, қазақы орнаменттер, адаптивті нұсқа
- script.js — интерактивті функциялар
- hero-mockup.png — визуал

Іске қосу:
1. Барлық файлды бір папкада сақтаңыз.
2. index.html файлын браузерде ашыңыз.

Интернетке шығару:
- GitHub Pages, Netlify немесе Vercel-ге осы папканы жүктеу жеткілікті.
- Бұл нұсқа серверсіз жұмыс істейді; кіру/қосылу және пайдаланушы жазбалары demo ретінде браузердің localStorage қоймасында сақталады.
